### EXECUTIVE SUMMARY

This document defines the complete digital experience, scroll storytelling narrative, interaction model, and mobile-first strategy for **Entrelinhas Store**, based on the explicitly approved **Direction B — "Boutique de Bairro"**.

The goal of this phase is to turn the strategic copywriting and visual identity into an engaging, fluid, and high-converting user journey that feels warm, transparent, and authentic — giving visitors the exact feeling of walking into a cozy neighborhood boutique.

### 4. INTERACTION MODEL & MICRO-INTERACTIONS

1. **Header Navigation Scroll Behavior:**
   * Default State: Transparent background with dark logo and navigation links.
   * Scrolled State (>80px): Transitions to `rgba(250, 248, 245, 0.92)` with `backdrop-filter: blur(8px)` and a subtle bottom border (`#E4E0D8`).

2. **Card Hover Effects:**
   * Transition: `transform 300ms cubic-bezier(0.16, 1, 0.3, 1), box-shadow 300ms ease`.
   * Lift: `transform: translateY(-4px)`.
   * Shadow: `box-shadow: 0 12px 30px -4px rgba(24, 23, 22, 0.08)`.

3. **WhatsApp Button Feedback:**
   * Hover: Brightens background (`#149E8E`), scales up slightly (`scale(1.02)`).
   * Active / Click: Scale down (`scale(0.98)`), initiates instant pre-filled WhatsApp message.

4. **Category Filter Tabs:**
   * Smooth active state indicator moving between filter tabs (*Todos*, *Alfaiataria*, *Vestidos*, *Uniformes*).

### 5. MOTION TOKENS & REDUCED-MOTION STRATEGY

#### Motion Specifications
* `--motion-duration-fast`: `150ms` (Buttons, micro-feedback)
* `--motion-duration-base`: `300ms` (Card reveals, tab switches)
* `--motion-duration-slow`: `500ms` (Section fade-ins)
* `--motion-easing-boutique`: `cubic-bezier(0.16, 1, 0.3, 1)`

#### Reduced-Motion Accessibility Overrides
For users with `prefers-reduced-motion: reduce`:
* All `translateY` and `scale` transform animations are disabled.
* Transitions default to instant opacity fades (`opacity 150ms ease`).
* No parallax or scrolling displacement effects.

* All CTA buttons: Minimum height **48px**, full container width or centered.
* Touch tap target gap: Minimum **12px** spacing between adjacent links/buttons.
